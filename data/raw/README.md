# Dataset setup

The current experiments use the datasets below. Paths are relative to the
repository root. Download the original files from the linked sources and
extract them into these locations; the training loaders do not fetch data.

## Files and sources

| Dataset | Rows used | Target | Required file |
|---|---:|---|---|
| Friedman | 10,000 | Friedman 1 response | Generated by `sklearn.datasets.make_friedman1`; no download |
| [Concrete](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength) | 1,030 | Compressive strength | `data/concrete+compressive+strength/Concrete_Data.xls` (included) |
| [California Housing](https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset) | 20,640 | Median house value, in $100,000 units | `data/raw/california_housing/CaliforniaHousing/cal_housing.data` |
| [Energy Efficiency](https://archive.ics.uci.edu/dataset/242/energy+efficiency) | 768 | `Y1`, heating load | `data/raw/energy_efficiency/ENB2012_data.xlsx` |
| [Yacht Hydrodynamics](https://archive.ics.uci.edu/dataset/243/yacht+hydrodynamics) | 308 | Residuary resistance | `data/raw/yacht_hydrodynamics/yacht_hydrodynamics.data` |
| [Auto MPG](https://archive.ics.uci.edu/dataset/9/auto+mpg) | 392 | Miles per gallon | `data/raw/auto_mpg/auto-mpg.data` |
| [Bike Sharing](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset) | 17,379 | `cnt`, hourly rentals | `data/raw/bike_sharing/hour.csv` |
| [Parkinsons Telemonitoring](https://archive.ics.uci.edu/dataset/189/parkinsons+telemonitoring) | 5,875 | `total_UPDRS` | `data/raw/parkinsons_telemonitoring/parkinsons_updrs.data` |

For California Housing, extract the
[original archive used by scikit-learn](https://ndownloader.figshare.com/files/5976036)
into `data/raw/california_housing/`, retaining its `CaliforniaHousing/`
subdirectory. A scikit-learn cached pickle is not the file expected by this
loader. For the UCI datasets, use the dataset page's Download link and retain
the file names shown above. Cite the individual dataset sources when using them.

## Splits and preprocessing

Scientific datasets use random splits with split seed 0. Nominal
train/validation/test proportions are 70/15/15 for Friedman, Energy, Yacht,
and Auto MPG; 60/20/20 for Concrete; and 80/10/10 for California. Exact indices
are saved with each run.

- Energy uses `Y1` in the reported benchmark. `Y2` is available through
  `--energy-target Y2` for a separate run.
- Auto MPG drops the six rows with missing horsepower, excludes car names,
  and encodes origin as three indicator columns, yielding nine inputs.
- Bike uses the hourly table in chronological order with a 60/20/20 split.
  `casual`, `registered`, and `instant` are excluded. Dates determine ordering;
  ordinary inputs are temperature, apparent temperature, humidity, and wind.
  Time, calendar, season, and categorical weather are context inputs.
- Parkinsons predicts later observations of the same 42 subjects. Each
  subject's observations are ordered by time and split 60/20/20. The other
  target, `motor_UPDRS`, is excluded. Voice measurements are ordinary inputs;
  subject identity, age, sex, and elapsed time are context inputs.
- Feature and target scalers are fitted on training rows. The reported MAE
  and RMSE are transformed back to the original target units.

The pairwise and higher-order interaction datasets are generated by
[`synthetic.py`](../../pure_resmlp/data/synthetic.py). They do not require
external files and are distinct from the Friedman benchmark.

## Local storage

Downloaded files under `data/raw/` are ignored by Git. The data-loading tests
require the files listed above. Concrete is the only real dataset included in
the repository; the other datasets are obtained from their original sources.
